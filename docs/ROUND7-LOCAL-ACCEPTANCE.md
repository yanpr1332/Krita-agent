# Round 7 local acceptance — 2026-11-10

**Technical fixture results are recorded. The finished-artwork gate failed.** The run tested source revision `696243f` with the coverage-pressure fix in this change. Compilation and 190 offline tests passed locally. Windows CI remains the separately recorded 189-test run for the earlier source revision.

Nine staged native fixtures ran on Krita Stable 5.3.4.1, Next Qt5 5.4.0-prealpha and Next Qt6 6.1.0-prealpha. Each build executed a landscape study, a cup still-life study and a character study as separate locally authored ScenePlan v4 candidates. Each had three stages. These were bounded structural test plans derived in part from the repository's generalist example, not generated model proposals or accepted finished pictures. The executor reviewed the fixture plans and issued a separate confirmation for each test stage. This is test execution consent, not an independent human artwork judgement.

All nine native runs completed their stage jobs, saved real Krita stage previews, and passed initial KRA/PNG integrity and strict fresh-copy reopen comparison with zero differing RGBA pixels and consistent recorded PNG color metadata. Each second and third stage changed actual pixels. Source sizes in UTF-8 bytes, expanded stroke counts, native step counts, preview hashes, layer counts and elapsed time are in [native evidence](acceptance-evidence/round7-native.json). The runs include stage checks and fresh reopen, so the timings are observations rather than benchmarks.

The workflow was reconstructed from its on-disk state after stage one. Missing stage confirmation was rejected, the live graph was inspected and the next stage was explicitly invoked. In a separate Qt6 fixture, the response was dropped after a real stage job was accepted. The native job completed, the controller remained `unknown_needs_review`, and a further submission was rejected with exactly one native submit. This check did not restart Krita after a stage boundary. That recovery case remains open.

A native Qt6 image exposed a coverage defect. Coverage scanlines were lowered to two points with weak default endpoint pressure, so the installed pressure-sensitive brush made thin lines instead of the intended block-in. The compiler now inserts a midpoint and uses constant 0.85 pressure when no curve was specified. An explicitly supplied curve remains authoritative. In the same Qt6 wall fixture, the region contained 8,727 nonwhite pixels before the fix and 80,305 after it, out of 84,480. This is a fixture observation, not a guarantee that any arbitrary spacing and brush will cover its polygon.

An independent visual reviewer inspected actual Qt6 sketch, color, detail and final images for all three subjects. All three failed as finished illustrations. The landscape retained an unfinished right mountain and empty band. The cup did not establish a readable rim or supporting surface. The character was a peach swatch and a gesture line without a recognizable figure. Per-layer native ablation showed seven visible-contributing layers for each Qt6 fixture, below the eight-layer full-artwork rule. No human review was fabricated. [Independent review](../artwork-results/round7-acceptance-20261110-163621/qt6-visual-review.json)

The test used executor-confirmed local stages and no paid model API. The independent artwork gate still needs complete recognizable multi-subject artworks and a human judgement. The user-requested API-free scope does not test real model planning. Failed versions, native checkpoints, stage images, layer comparisons and real Krita screenshots remain in the [local run](../artwork-results/round7-acceptance-20261110-163621/).
