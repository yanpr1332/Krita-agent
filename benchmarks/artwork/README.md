# Artwork acceptance benchmark

The checked-in \`reference/sunset_alpine_lake.jpg\` is an original complexity example for the real visual reviewer. \`contracts/sunset_alpine_lake.v1.json\` is the fixed machine-readable acceptance specification. Both are mandatory inputs during **artwork acceptance**; neither is a finished artwork produced by Krita Agent.

Do not measure scene completeness by stroke count, file size, number of layers alone, or similarity to a synthetically generated grid. The reference is an illustration and does not prescribe exact pixel colors or brush engine.

The source image is generated by \`scripts/create_artwork_reference.py\`. See the audit rules and local artifact directory in \`docs/ARTWORK-ACCEPTANCE.md\`.
